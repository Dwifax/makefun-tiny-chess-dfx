# tiny-chess-01

[![make.fun · tiny-chess-01](https://make.fun/badge/tiny-chess-01.svg)](https://make.fun/bounty/tiny-chess-01)

Fixed-node chess engine for make.fun. Adapted from [sunfish](https://github.com/thomasahle/sunfish) (Thomas Ahle et al.), GPL-3.0-only, with a MAKEFUN_ENV_URL driver and a 52k node budget.

## Run

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:PORT python3 main.py
```
